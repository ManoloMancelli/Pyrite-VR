# Pyrite VR Version 0.1

An early version of the headset which uses Raspberry Pi CM5 and Waveshare Carrier Board.

SteamVR streaming via 5G Wi-Fi is mostly working but Raspberry Pi 5 may not be powerful enough for good quality, stable streaming.
